# AI Travel Agent

An AI-powered travel assistant for trip planning and travel information.

## Current Status
Project setup / frontend development

## Tech Stack
- **Frontend**: React + Vite
- **Language**: JavaScript (ES Modules)

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
